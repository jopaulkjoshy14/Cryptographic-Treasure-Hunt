How it works

The application keeps the encryption and decryption process inside the browser.

1

Write a message

The organizer enters the message that should remain hidden.

2

Encrypt locally

AES-256-GCM encrypts the message in the organizer's browser.

3

Share the clue

The organizer shares the ciphertext and key with the participant.

4

Reveal the treasure

The participant decrypts the ciphertext locally to reveal the original message.

Privacy by design: encryption and decryption happen in the browser. The application does not require a backend server to process the secret message.
